Adaptive Shared-Control Framework for Fixed-Wing UAVs

A telemetry-driven system investigating adaptive control authority scaling for novice fixed-wing UAV pilots using real-world flight data.

Research Question

How effectively can pilot instability be inferred from low-cost UAV telemetry and used to improve flight stability while preserving pilot intent in novice-operated flights?

System Overview

Pilot Input
    ↓
AI Instability Estimation (PIS)
    ↓
Control Authority Scaling Layer
    ↓
INAV Flight Controller
    ↓
Aircraft

Objective

To reduce crash rate and improve flight stability during early-stage RC aircraft training by dynamically adjusting control sensitivity based on pilot behaviour.

Current Status

  • ✔ Airframe constructed
  • ✔ Control surfaces tested on ground
  • ⏳ Flight controller integration pending
  • ⏳ First flight data not yet collected
  • ⏳ ML model not trained

Evaluation Metrics

  • Crash rate reduction
  • Roll variance reduction
  • Oscillation frequency reduction
  • Pilot control stability (PIS variance)

This project is part of an independent research initiative on human-in-the-loop control systems for UAV platforms.
