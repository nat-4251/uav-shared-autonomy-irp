CHALANT
Cooperative Human–AI Learning Architecture for Novice Training
SCROLL ↓
Project Foundation

Description

A telemetry-driven shared-control system investigating adaptive control authority scaling for novice fixed-wing UAV pilots using real-world telemetry and behavioural flight data.

Objective

To reduce crash rate and improve aircraft stability during early-stage RC pilot training by dynamically adjusting control sensitivity based on inferred pilot instability.

The Big Question
Can pilot instability be reliably inferred from UAV telemetry to enhance stability without overriding pilot intent?
System Architecture

Human + AI Shared Control

The aircraft operates using a layered shared-control framework where pilot intent is preserved while adaptive authority scaling selectively suppresses unstable or excessive control behaviour.
