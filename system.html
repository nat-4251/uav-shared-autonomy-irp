SYSTEM
Internal architecture of the CHALANT adaptive shared-control UAV framework.
Architecture Overview

CHALANT operates using a human-in-the-loop adaptive stabilization framework that dynamically modifies aircraft control authority based on inferred pilot instability. The system preserves intentional pilot maneuvers while selectively suppressing unstable or excessive control behaviour using telemetry-derived behavioural analysis.

Core Components
01

Pilot Input Layer

Manual control commands are interpreted as the primary representation of pilot intent.

02

Telemetry Collection

Aircraft telemetry including roll, pitch and control oscillation behaviour is continuously monitored.

03

Instability Estimation

Behavioural indicators are used to infer pilot instability and overcorrection tendencies.

04

Authority Scaling

Control authority is dynamically modified to stabilize aircraft behaviour without overriding intent.

05

Flight Execution

Stabilized commands are executed through the INAV flight controller and fixed-wing UAV platform.

Control Flow

01

Pilot performs manual control input through transmitter.

02

Receiver transmits pilot commands to the flight controller.

03

Flight telemetry is collected continuously during operation.

04

Pilot instability estimation evaluates behavioural control patterns.

05

Adaptive authority scaling selectively modifies unstable control input.

06

Stabilized control commands are executed by the aircraft platform.
