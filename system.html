SYSTEM
Internal architecture of the CHALANT adaptive shared-control UAV framework.
Architecture Overview
CHALANT operates using a human-in-the-loop adaptive stabilization framework that selectively modifies aircraft control authority based on inferred pilot instability.
Core Components

Pilot Input Layer

Manual pilot commands are transmitted through the radio control system and interpreted as the primary expression of pilot intent.

Telemetry Collection

Flight telemetry including roll angle, pitch angle, stick reversal frequency and control oscillations are logged for behavioural analysis.

Instability Estimation

The system estimates pilot instability using telemetry-derived behavioural indicators associated with overcorrection and unstable flight handling.

Adaptive Authority Scaling

Aircraft control sensitivity is dynamically modified to suppress unstable inputs while preserving deliberate pilot maneuvers.

INAV Flight Controller

The Matek F405-Wing V2 flight controller executes stabilization and aircraft control using sensor fusion and assisted flight logic.

Fixed-Wing Aircraft Platform

The foam fixed-wing UAV serves as the physical experimental platform for telemetry collection and real-world validation flights.
